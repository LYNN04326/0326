附註｜前端唯一的特殊規則

除了「BenefitKind = 1 的項目抽出放第一個分類」這一條之外， 前端不做任何分類判斷 —— 分類名稱、分類順序、項目名稱、項目順序全部照 API 回傳值依序呈現。
