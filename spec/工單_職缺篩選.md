【標題】數據統計查詢：新增「職缺篩選」下拉選單與說明 tooltip

【頁面】企業會員後台 › 數據統計查詢
【檔案】LogCalculateWeek.aspx / LogCalculateYear.aspx / LogCalculateHistory.aspx（三頁皆需一致）
【對應任務卡】數據統計查詢－新增數據分類篩選

────────────────────────────
一、需求說明
────────────────────────────
因客服反映：現行數據統計需先下載全部職缺報表，再用 Excel 篩選才能辨識哪些職缺有履歷數據，
第一線人員無法即時判讀，操作相對不便。故於「匯出報表／列印報表」那一列的左側新增
「篩選：」下拉選單與說明圖示，讓使用者直接切換要顯示的職缺範圍。

────────────────────────────
二、設計說明（重要）
────────────────────────────
1. 本次調整全數採用現版既有樣式，未新增任何視覺元件，故不另出 Figma 檔。
   各元件的樣式取樣位置已在附件「樣式沿用來源」圖上圈出：
     ① 「篩選：」標籤 → 沿用查詢列標籤（「屬性：」）的字級與顏色，僅加粗。
     ② 下拉選單 → 沿用查詢列既有 select（同「屬性」／「職缺顯示狀態」），不另做樣式。
     ③ 新增元件位置 → .searchmail 內 <br> 之後、.floatR 之前，沿用既有 .floatL。
     ④ 匯出報表／列印報表 → 位置與樣式維持不變。
     ⑤ 說明圖示「?」與 tooltip → 沿用站上既有說明元件樣式
        （例：職缺編輯頁「立即上工 ?」的藍色圓形問號與白底說明泡泡）。

2. 請依示意圖切版，HTML 標籤沿用現有結構與命名慣例（.floatL、select、既有說明元件），
   不需為此功能另建一套版型。

3. 附件之示意語法僅供參考，實際以切版成果為主；class 命名、樣式歸屬（共用 CSS 或頁面
   專用）可依前端既有規範調整，只要視覺與行為符合本工單即可。

────────────────────────────
三、功能規格
────────────────────────────
1. 篩選欄位
   標籤：「篩選：」（兩字加粗）
   元件：下拉選單（single select）
   選項（依序）：
     - 全部職缺           value=all
     - 僅顯示有數據職缺   value=hasData ← 預設值
     - 僅顯示有主投職缺   value=mainApply
   行為：切換選項時，以目前查詢條件重新查詢並重繪報表（沿用既有查詢／AJAX）；
         按「查詢」後，篩選值需保留。
   定義：「有數據」＝瀏覽統計、應徵統計、曝光數統計任一項不為 0。（如與現行定義不同請回覆確認）

2. 說明圖示與 tooltip
   圖示：藍色圓形「?」，置於下拉選單右側，間距約 6px。
   觸發：滑鼠移入顯示、移出隱藏；手機／平板為點擊切換，點其他區域關閉。
   文字：數據指瀏覽統計、應徵統計、曝光數統計
   樣式：白底、淡藍色細框、圓角、黑字，上方帶小箭頭。
   位置：以「?」為定位基準顯示於其正下方，箭頭對準「?」中心，
         「?」位置變動時 tooltip 需跟著移動。

3. 插入位置（已對照實際頁面原始碼確認）
   <div class="searchmail ">
     <div class="floatL"> …屬性…職缺顯示狀態…起始日期…關鍵字…查詢… </div>
     <br>
     ★ 新增的篩選區塊放這裡（沿用 .floatL）★
     <div class="floatR"> 匯出報表／列印報表 </div>
     <div class="clear"></div>
   </div>

   限制：.searchmail 為 width:710px、height:43px、背景圖 se_bg2.gif，
         請勿更動其 height 與 background，否則查詢列灰底框線會消失。

────────────────────────────
四、不得更動
────────────────────────────
- 匯出報表／列印報表：位置、樣式、既有功能全部維持原狀。
- 查詢框（.searchmail）樣式不得更動。
- 新增元件不可與職缺標題／新增日／曝光數說明等文字重疊。

────────────────────────────
五、驗收條件
────────────────────────────
1. 三頁（本週／年度／歷史）都看得到篩選列，預設值為「僅顯示有數據職缺」。
2. 切換三個選項，報表資料正確變動；重新查詢後篩選值保留。
3. 「篩選：」左緣與上一列「屬性：」左緣切齊；按鈕位置與改版前一致。
4. 滑鼠移入「?」顯示指定文字，樣式與位置符合規格；手機點擊可顯示與關閉。
5. 列印報表輸出內容不含篩選列。
6. 查詢列灰底框線與高度與改版前一致（無破版）。
