# 職缺篩選　畫面預覽說明（內部用，非工單內容）

不用等工程師上版，可在自己的瀏覽器上先看效果。**只是暫時預覽，重新整理就會消失，不會影響線上資料。**

## 步驟

1. 用 Chrome 或 Edge 登入企業會員後台，開啟 [數據統計查詢－本週統計](https://recruit.1111.com.tw/LogCalculateWeek.aspx)
2. 按 **F12** 開啟開發者工具（Mac：⌥⌘I），切到 **Console** 分頁
3. 第一次使用會出現黃色警告，要求輸入 `allow pasting`：
   在 Console 最下方 `>` 游標處**手動輸入** `allow pasting`，按 Enter（這串字不能用貼的）
4. 貼上下方整段程式碼，按 Enter
5. 畫面上「匯出報表／列印報表」那一列的左側就會出現 `篩選：` 下拉選單與 `?` 說明圖示；
   滑鼠移到 `?` 上會跳出說明泡泡

## 程式碼

```js
(function(){
  var sm=document.querySelector('.searchmail'), fr=sm&&sm.querySelector('.floatR');
  if(!fr){alert('找不到 .floatR');return;}
  var css=document.createElement('style');
  css.textContent=`
.jobFilter{clear:left;line-height:40px;}
.jobFilter b{font-weight:bold;}
.jobFilter select{vertical-align:middle;}
.jobFilter .jfTip{position:relative;display:inline-block;vertical-align:middle;line-height:normal;}
.jobFilter .jfIcon{display:inline-block;width:16px;height:16px;margin-left:6px;border-radius:50%;
 background:#2f86d3;color:#fff;font-size:11px;line-height:16px;font-style:normal;font-weight:bold;
 text-align:center;cursor:pointer;vertical-align:middle;}
.jobFilter .jfTipBox{position:absolute;top:26px;left:-4px;z-index:999;display:none;white-space:nowrap;
 padding:11px 14px;border:1px solid #bcd6ea;border-radius:8px;background:#fff;
 box-shadow:0 2px 8px rgba(0,0,0,.08);color:#000;font-size:12.5px;line-height:1.7;}
.jobFilter .jfTipBox::before,.jobFilter .jfTipBox::after{content:"";position:absolute;left:14px;border:8px solid transparent;}
.jobFilter .jfTipBox::before{top:-17px;border-bottom-color:#bcd6ea;}
.jobFilter .jfTipBox::after{top:-15px;border-bottom-color:#fff;}
.jobFilter .jfTip:hover .jfTipBox,.jobFilter .jfTipBox.is-show{display:block;}`;
  document.head.appendChild(css);
  var d=document.createElement('div');
  d.className='floatL jobFilter';
  d.innerHTML='<b>篩選：</b>'+
    '<select id="selJobFilter"><option value="all">全部職缺</option>'+
    '<option value="hasData" selected>僅顯示有數據職缺</option>'+
    '<option value="mainApply">僅顯示有主投職缺</option></select>'+
    '<span class="jfTip"><i class="jfIcon" id="jfIcon">?</i>'+
    '<span class="jfTipBox" id="jfTipBox">數據指瀏覽統計、應徵統計、曝光數統計</span></span>';
  fr.parentNode.insertBefore(d, fr);
  var ic=document.getElementById('jfIcon'), box=document.getElementById('jfTipBox');
  ic.onclick=function(e){e.stopPropagation();box.classList.toggle('is-show');};
  document.addEventListener('click',function(){box.classList.remove('is-show');});
})();
```

## 注意

- 這段只加畫面元件，**下拉選單不會真的篩選資料**（篩選邏輯由後端開發）。
- 關閉或重新整理頁面即還原，不會留下任何變更。
- 年度統計、歷史統計兩頁也可以用同一段程式碼預覽。
