# 【後端】數據統計查詢：職缺篩選資料判定與查詢串接

---
## 一、需求位置

**頁面**：數據統計查詢
**適用範圍**：以下兩個分頁皆需一致
[本週統計](https://recruit.1111.com.tw/LogCalculateWeek.aspx)　
[年度統計](https://recruit.1111.com.tw/LogCalculateYear.aspx)

---
## 二、需求說明

配合前端新增的 `篩選：` 下拉選單（畫面與互動已完成，見需求檔案分支），
提供職缺篩選的資料判定、查詢串接、篩選值保存，以及匯出／列印報表套用篩選。

### 1. 篩選條件與資料判定

| 顯示文字 | 判定條件 |
| --- | --- |
| 全部職缺 | 不篩選，維持現行結果 |
| 僅顯示有數據職缺 | `瀏覽統計`、`應徵統計`、`曝光數統計` 任一項不為 0（**預設值**） |
| 僅顯示有主投職缺 | `應徵統計` 不為 0 |

- 統計數值以該分頁現行的統計區間與查詢條件為準，不另外定義計算方式。
- 篩選僅影響「顯示哪些職缺」，不影響各職缺的統計數值計算。

### 2. 查詢行為

1. 篩選欄位變更時即重新查詢並回傳結果，**不需按 `查詢`**。
2. 重新查詢須沿用畫面上目前的 `屬性`、`職缺顯示狀態`、`起始日期`、關鍵字等條件，
   這些欄位的值不可被清空或重設。
3. 除篩選以外的其他查詢條件維持原行為：修改後仍需按 `查詢` 才會套用。
4. 查詢完成後篩選值需保存並回填，切換分頁、重新整理、PostBack 後皆維持使用者選取的值。
5. 建議以局部更新處理（頁面既有 `UpdatePanel` 可沿用），避免整頁重載造成等待。

### 3. 匯出與列印

- `匯出報表`、`列印報表` 需套用**目前的篩選條件與查詢條件**，不再輸出全部職缺。
- 匯出檔案的欄位、格式、檔名規則維持現行不變。

### 4. 不得更動

- 現有查詢條件（`屬性`、`職缺顯示狀態`、`起始日期`、關鍵字）的行為與預設值。
- 報表欄位與各項統計數值的計算邏輯。
- 匯出檔案的欄位與格式。
- 歷史統計頁不在本次調整範圍，維持現狀。

### 5. 驗收條件

1. 兩個分頁預設皆為 `僅顯示有數據職缺`，報表僅列出符合條件的職缺。
2. 切換為 `全部職缺` 時，結果與改版前一致。
3. 切換為 `僅顯示有主投職缺` 時，僅列出 `應徵統計` 不為 0 的職缺。
4. 切換篩選後未按 `查詢` 即自動更新；更新後 `屬性`、`職缺顯示狀態`、`起始日期`、
   關鍵字與篩選值皆維持不變。
5. 修改其他查詢條件時，仍需按 `查詢` 才套用。
6. `匯出報表`、`列印報表` 的內容與畫面上顯示的職缺一致（含篩選條件）。
7. 歷史統計頁行為與改版前一致。

### 6. 本工單範圍外（前端已完成）

- `篩選：` 下拉選單與說明 tooltip 的版面、樣式與互動（見需求檔案分支）。
