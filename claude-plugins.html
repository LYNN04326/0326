Claude Code 外掛安裝指令

在 Claude Code 中直接貼上下列指令即可安裝，一個區塊就是一組完整指令。

1. superpowers

測試、除錯、協作一整套。

安裝指令

/plugin marketplace add anthropics/claude-plugins-official
/plugin install superpowers@claude-plugins-official
原始出處：github.com/anthropics/claude-plugins-official

2. claude-mem

關掉重開，記得上次做到哪。

安裝指令

/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem@thedotmack
原始出處：github.com/thedotmack/claude-mem

3. codex

叫 OpenAI 的 Codex 來複查。

安裝指令

/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
原始出處：github.com/openai/codex
安裝後請重新啟動 Claude Code，外掛才會生效。
